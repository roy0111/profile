# Interview Prep Guide

A comprehensive, premium-quality Java/Spring Boot interview preparation dashboard, plus a React troubleshooting scenarios page. Built with vanilla HTML, CSS (glassmorphism dark/light theme), and JavaScript — no framework needed.

## Pages

| Page | Description |
|---|---|
| `interview.html` | 302+ Q&A cards covering Java, Spring Boot, Microservices, Kafka, Databases, Algorithms, and React |
| `react_scenarios.html` | 20 React-specific troubleshooting scenarios with interactive sidebar, search, and progress tracker |

## Features

- **Dark / Light Theme** — persisted in `localStorage`, synced across both pages
- **Full-text Search** — live filter + keyword highlighting
- **Category Sidebar** — scroll-spy navigation with active state
- **Collapsible Q&A Cards** — smooth CSS transitions
- **"Mark Mastered" Tracker** — per-category progress ring (persistent)
- **Copy-to-Clipboard Code Blocks** — syntax-highlighted with Prism.js
- **Cross-page Navigation** — seamless links between core guide and React Scenarios page

## Topics Covered (interview.html)

- Java 8 & 17 Features (Streams, Lambdas, Records, Sealed Classes)
- JVM & Multithreading (GC, memory, concurrency)
- OOP & Design Patterns
- Spring Core & AOP
- Spring Boot & Exception Handling
- Spring WebFlux & Reactive Programming
- REST APIs & Security (JWT, OAuth2)
- Microservices & Cloud (ECS, Kubernetes, AWS)
- Apache Kafka (producers, consumers, lag, idempotency)
- Databases & Transactions (HikariCP, locking, indexing)
- Algorithms & Data Structures
- React Framework (3 YOE) — hooks, state, routing, performance

## React Scenario Topics (react_scenarios.html)

- Hooks & Lifecycle (useEffect, Strict Mode, cleanup)
- Performance & Scaling (virtualization, debouncing, useMemo)
- State Sharing & Cache (Context, Redux, TanStack Query)
- Routing, Auth & Security (protected routes, 401 refresh, SPA 404)
- User Actions, Errors & Deployment (idempotency, global errors, white screen)
